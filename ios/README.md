# Pip Bridge — приложение-мост для iPhone

Что делает:
- **Ассистент.** Зажал нижнюю кнопку на лице Пипа → говоришь → отпустил. Голос идёт на iPhone (IMA ADPCM, 16 кГц, ~8 КБ/с),
  распознаётся на самом телефоне, вопрос уходит в Claude, короткий ответ возвращается текстом на экран Пипа.
  На экране ответа: верхняя кнопка — прочитать вслух с телефона, нижняя — назад.
- **Wi-Fi.** Список сетей Пипа (до 8): добавить, сменить пароль, удалить. Пока Пип только хранит их (NVS) — для домашнего сервера.
- **Статус.** Батарея, прошивка, сигнал, память, журнал связи.

Уведомления и музыка приложению не нужны: Пип берёт их у iOS напрямую (ANCS/AMS), даже когда приложение закрыто.

## Установка (бесплатный Apple ID)

1. Прошей свежую прошивку (в ней сервис моста). Пип должен быть подключён к iPhone: Настройки → Bluetooth → Pip.
2. Открой `ios/PipBridge.xcodeproj` в Xcode 16 или новее.
3. Таргет PipBridge → Signing & Capabilities → Team: свой Apple ID (Personal Team).
   Если Xcode ругается на Bundle Identifier — поменяй `com.zharovegor.PipBridge` на любой свой.
4. iPhone по кабелю (или по Wi-Fi), выбери его сверху и нажми Run.
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему сертификату разработчика.
   Нужен включённый «Режим разработчика» (Настройки → Конфиденциальность и безопасность).
6. В приложении: разреши Bluetooth и распознавание речи, во вкладке «Настройки» вставь ключ Claude API.

Подпись бесплатного аккаунта живёт 7 дней — потом просто снова Run из Xcode (данные приложения сохраняются).

## Если не видит Пипа

- Вкладка «Pip» показывает состояние и журнал связи.
- «Прошивка без моста» после прошивки: выключи и включи Bluetooth на iPhone — iOS перечитает список сервисов.
- Приложение работает в фоне (bluetooth-central): после первого запуска iOS сама будит его, когда Пип просит.
  Распознавание речи в фоне iOS иногда не даёт — тогда Пип покажет причину; открой приложение.

## Протокол

Описан в начале раздела «the bridge» в `firmware/main/ble.c`. UUID сервиса `50495042-5249-4447-4500-000000000001`.
Декодер голоса `PipBridge/ADPCM.swift` сверяется при запуске с вектором из `sim/adpcm_test` — держи их в паре с `ui/adpcm.c`.
